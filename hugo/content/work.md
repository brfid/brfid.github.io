## Documentation

### [DomainTools documentation platform](https://docs.domaintools.com/)

DomainTools provides internet infrastructure intelligence.

- **Audiences:** SOC analysts: alert triage; threat hunters and incident responders: infrastructure investigation; administrators: access and integration setup; developers: API integration.
- **Contribution:** Documentation platform development; publishing tools for [developer resources](https://docs.domaintools.com/resources/) and the [changelog](https://docs.domaintools.com/changelog/); final editorial review.

## Projects

### [ARPANET Redux](https://github.com/brfid/arpanet-redux)

- Recovered 1973 ARPANET switching software connects simulated PDP-10 and PDP-11 hosts.
- **Contribution:** Modern [orchestration](https://github.com/brfid/arpanet-redux/blob/main/docs/architecture.md), validation, and documentation around preserved systems and existing simulators. A documented link-cut test keeps a TELNET session connected.

### [aghist](https://github.com/brfid/aghist)

- Experimental Python engine for historical research with agent teams.
- **Contribution:** Research workflows with versioned questions, preserved source passages, independent reviews, and offline tests.

### [AUTODIN II and TCP/IP](https://github.com/brfid/autodin-ii-tcpip)

- Historical research on defense networking requirements and the development of TCP/IP.
- Archival sources, evidence notes, and a [working manuscript](https://github.com/brfid/brfid.github.io/blob/main/hugo/content/posts/tcpip-autodin-ii/index.md).
